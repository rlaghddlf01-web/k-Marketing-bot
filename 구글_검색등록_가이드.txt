🛸 [Universal Expat Growth Engine] 구글 검색 자동 등록(SEO) 가이드
========================================================================

대표님, 나중에 실제 웹사이트 도메인이 확정되셨을 때 
아래 2가지 단계대로 진행해 주시면 구글 검색창에 6,630개 페이지가 자동으로 노출됩니다.

------------------------------------------------------------------------
📌 [1단계] Google Search Console 사이트맵 등록 (필수 - 약 3분 소요)
------------------------------------------------------------------------
구글 검색 로봇에게 "우리 사이트의 6,630개 다국어 페이지 주소를 긁어가라"고 알려주는 공식 절차입니다.

1. 웹 브라우저에서 아래 주소로 접속하여 구글 계정으로 로그인합니다.
   👉 https://search.google.com/search-console

2. [속성 추가]를 누르고 대표님의 실제 웹사이트 도메인(URL)을 입력합니다.
   (예: https://k-market.app 또는 https://ktrs-market.vercel.app)

3. 소유권 확인 완료 후, 좌측 메뉴에서 [Sitemaps (사이트맵)]을 클릭합니다.

4. [새 사이트맵 추가] 입력칸에 아래와 같이 입력하고 [제출] 버튼을 누릅니다.
   👉 sitemap.xml

5. 완료! (구글 로봇이 며칠 내로 전국 대학+공단+외국인동네 6,630개 페이지를 자동 색인합니다.)


------------------------------------------------------------------------
⚡ [2단계] Google Indexing API 실시간 초고속 색인 연동 (선택 - 1~2시간 만에 노출)
------------------------------------------------------------------------
사이트맵 제출보다 훨씬 빠르게, 새 글/페이지가 생기자마자 1~2시간 만에 구글 1페이지에 올리고 싶을 때 사용합니다.

1. Google Cloud Console 접속
   👉 https://console.cloud.google.com/

2. 상단 검색창에 "Web Search Indexing API"를 검색하고 [사용] 버튼을 누릅니다.

3. 좌측 [사용자 인증 정보] -> [사용자 인증 정보 만들기] -> [서비스 계정(Service Account)] 선택

4. 서비스 계정 생성 후 [키(Keys)] 탭에서 [키 추가] -> [JSON]을 선택하여 키 파일을 다운로드합니다.

5. Google Search Console로 돌아와서 [설정] -> [사용자 및 권한]에서 
   방금 생성한 서비스 계정 이메일(예: my-bot@project.iam.gserviceaccount.com)을 [소유자(Owner)] 권한으로 추가합니다.

6. 다운로드한 JSON 키 파일 이름을 `service_account.json`으로 바꾸고 
   `kmarket-marketing-engine` 폴더 안에 넣어주시면 끝!
   (이후부터는 마케팅 봇이 구글 봇에게 자동으로 실시간 색인 신호를 쏩니다.)
